# QuickTranslate 功能扩展路线图

> 规则：先修核心路径和状态正确性，再扩展功能。每个模块都必须独立 PRD/acceptance criteria，不能与 QT-001～QT-005 的核心修复混在同一个大 PR。

## R0 — 核心可靠性（必须先完成）

- 修正 macOS 光标锚点与 clipboard change token。
- 统一所有 translation event 的 latest-wins 语义。
- 修正跨平台外链打开。
- 让 provider 验证成本/配额与 UI 文案一致。
- 使错误状态、storage retention 和配置批次结果可信。
- 为结构化文本建立保真方案。

## R1 — 隐私与行为控制

### 1. 隐身翻译 / 不存历史

**用户价值**：临时翻译敏感信息，而不将源文/译文保留在历史中。  
**功能边界**：用户能在托盘或设置中切换；启用期间不写历史，也需明确缓存是否禁用；当前会话结束后状态应如何恢复需要产品定义。

**验收**：翻译 UI 正常工作；DB 中无此模式下生成的历史/缓存条目；开启/关闭后 UI 明确显示当前状态；无隐式上传。

### 2. 敏感内容本地检测

检测典型 API tokens、private key markers、密码形式等。默认避免过度积极拦截普通文字；支持用户选择“跳过翻译”“仍然翻译一次”。所有规则在本机运行，不把命中的原文上传。

**验收**：真实样例与假阳性集；正文不得进入日志；被阻止时 UI 告知稳定原因码而非展示敏感片段。

### 3. 按应用排除剪贴板监控

在 OS 能可靠取到当前前台应用标识的平台，允许把应用加入 exclude list。需要先核对权限、沙盒和系统限制；不能宣称在 Windows 与 macOS 的所有场景中都能识别同样的进程信息。

**验收**：排除列表持久化、可编辑；被排除应用复制不触发翻译；重新切回允许应用后正常工作；不可读取应用信息时执行明示的安全降级。

## R2 — Provider 能力与可诊断性

### 4. Provider 能力矩阵

为每个 provider 维护显式 capability metadata：凭证需求、支持语言/语言变体、验证方式、文本限制、是否 best-effort、默认 timeout/retry policy、可用区域/endpoint 类型。避免能力信息继续散落在 UI、mapper 和 fallback 条件里。

**验收**：单一数据来源生成设置页说明与测试；fallback 不选择无法满足目标语言的 provider，除非 UI 明确告知降级。

### 5. Fallback 可观察性

展示当前结果实际来源、是否 fallback、上游失败的用户安全摘要；诊断页显示 provider health state/上次错误类别和恢复时间。不要默认显示每个失败响应 body。

**验收**：在线成功、fallback 成功、所有 provider 失败、未配置 key、同语言输入能区分，不出现误报“网络断开”。

### 6. 用户主动诊断导出

导出版本、OS、runtime health、provider 状态、事件错误码、测试结果摘要。导出前提供预览，默认脱敏并排除剪贴板正文、译文、key、签名、用户路径。

**验收**：含敏感 sentinel 的测试记录导出后仍脱敏；用户可取消；导出文件仅保存到用户选择的位置。

## R3 — 输入与翻译能力

### 7. 结构化文本保真

让用户可选择“自然语言优化”与“保留原格式”倾向；为终端输出、代码块、列表、表格建立保守的本地检测规则。不要保证翻译能完全保留可执行代码语义。

**验收**：原文始终可复原；provider request text 与历史存储策略有文档；缩进/换行测试通过。

### 8. 可配置快捷键与触发方式

除复制触发之外，评估全局快捷键手动触发、暂停/恢复、只翻译选中文本等扩展。必须防止快捷键冲突和对其他应用输入的拦截，遵循现有 non-activating popup 行为。

**验收**：快捷键注册/冲突/释放失败的错误状态明确；按键不会误触发或影响输入；平台能力差异公开。

### 9. OpenAI-compatible / 自托管 / 本地 provider

将它视作单独的架构扩展。先定义 `TranslationProvider` 配置 schema、authentication、streaming（如有必要）、timeout/budget、model list、错误分类、隐私说明与 endpoint 安全策略。不能只把 arbitrary URL 输入框加入设置。

**验收**：mock server 契约测试；凭证加密/脱敏；endpoint allowlist/SSRF 方案通过安全检查；请求/响应大小、重定向、超时和 fallback 语义确定。

### 10. OCR / 图片翻译（远期）

OCR 会涉及截图权限、图像缓存、敏感图片数据、语言/布局检测与更大性能成本，应单独立项。不要将全屏截图默认上传到翻译服务，也不要为了此功能修改普通文本路径的可靠性。

## 产品指标建议

不以“加了多少功能”为指标。建议每个版本跟踪本地可计算、无需上传正文的质量指标：

- clipboard worker 重启次数；
- latest-wins stale event 被丢弃次数；
- popup show/position 失败数；
- provider fallback 成功次数与总时延分布；
- history/cache 写入与清理失败次数；
- 每平台自动化与手工回归覆盖状态。

这些指标默认仅保存在本机。任何网络遥测必须 opt-in、聚合、说明收集字段且不能包含输入文本或凭证。
